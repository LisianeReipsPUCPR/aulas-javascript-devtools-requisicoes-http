    Comece aqui

    Tour guiado

    Tudo dentro do DevTools é clicável. Atalhos F8 F10 F11 Shift+F11 funcionam enquanto o código estiver pausado.

    Você sabia? Em 1947, a equipe de Grace Hopper encontrou uma mariposa de verdade presa no computador Harvard Mark II e colou o inseto no caderno de registros. A palavra "bug" já existia, mas a história pegou. Desde então, debugar é tirar os insetos do código.

    Tipos de erro

    Cada um tem um botão que roda o exemplo no Console do simulador lá em cima. Veja a mensagem que aparece.

    SyntaxError

    Escrevemos errado: falta ( ) ou { }. O código nem chega a rodar.

    if (x > 3 {

    ReferenceError

    Usamos algo que não existe, quase sempre um nome digitado errado.

    console.log(nme);

    TypeError

    Usamos algo do jeito errado, como ler uma propriedade de null.

    null.textContent

    Erro de lógica

    Roda sem erro, mas o resultado está errado. O mais traiçoeiro: o console não avisa nada.

    "5" + "1"   // "51"

    Lendo o erro

    A mensagem de erro é uma pista, não uma bronca. Clique em cada pedaço.

    Uncaught TypeError: Cannot read properties of null (reading 'addEventListener') at script.js:3
    O QUÊ?TypeErrorO tipo do erro. Diz a família do problema: aqui, usamos um valor do jeito errado.
    POR QUÊ?Cannot read… of nullTentamos chamar addEventListener em null: o querySelector não encontrou o elemento (seletor errado ou script rodando antes do HTML existir).
    ONDE?script.js:3Arquivo e linha. No DevTools esse texto é um link: clique e ele abre o Sources na linha exata.

    Controles do debugger

    Com o código pausado, você é o controle remoto.

    BotãoWindows / LinuxMacO que faz
    ResumeF8F8 ou ⌘+\Continua até o próximo breakpoint.
    Step overF10F10 ou ⌘+'Executa a linha inteira e vai para a próxima. Se a linha chama uma função, ela roda toda sem você entrar.
    Step intoF11F11 ou ⌘+;Entra dentro da função chamada na linha.
    Step outShift+F11Shift+F11 ou ⌘+Shift+;Termina a função atual e volta para quem a chamou.

    O método do detetive

    A ordem importa: sem reproduzir o bug, não dá para saber se você corrigiu.

    1. ReproduzaDescubra os passos exatos que fazem o bug aparecer. Aqui: digitar 5 e 1 e clicar.
    2. Leia o erroTipo, mensagem e arquivo:linha. Se não há erro, é bug de lógica.
    3. Desconfie de um lugar"A soma está errada, então o problema está onde a soma é feita."
    4. Pause aliBreakpoint de linha, de evento (click) ou a palavra debugger;.
    5. ObserveScope e Watch mostram os valores reais. typeof sum entrega o culpado.
    6. Corrija e testeMude uma coisa só, desative os breakpoints e rode de novo.

    Cuidado!

    Não leia só a 1ª linhaOlhe o arquivo e a linha (script.js:3): eles levam ao culpado.
    Mude uma coisa por vezTrocar cinco coisas juntas esconde qual delas resolveu.
    Limpe a cena do crimeApague console.log e debugger extras antes de entregar.
    Explique para o patinhoContar o código em voz alta (rubber duck) revela muito bug.

    Vamos praticar?

    Tente sozinho primeiro. As dicas abrem uma de cada vez; a resposta fica por último.

    3 bugs · use o Console

    1) A média que não sai

    Deveria mostrar a média ≈ 8.17.

    const alunos = ["Ana", "Bruno", "Carla"];
const notas = [8.5, 7, 9];
let soma = "0";
for (let i = 1; i < notas.length; i++) {
  soma += notas[i];
}
console.log("Média: " + soma / alunos.lenght);
    DicaColoque console.log(i, soma) dentro do for. Qual é o primeiro i? E qual o tipo de soma?
    Resposta
    • let soma = "0" é texto: += concatena. Use 0.
    • O for começa em i = 1 e pula a Ana. Use i = 0.
    • alunos.lenght não existe (é undefined) e a divisão dá NaN. É length.
    2 bugs · use breakpoints e Watch

    2) O maior número

    Faça no Sources › Snippets: cole, clique no número da linha e rode com Ctrl+Enter.

    function maior(lista) {
  let maior = 0;
  for (const n of lista) {
    if (n < maior) maior = n;
  }
  return maior;
}
console.log(maior([3, 9, 4]));    // esperado 9
console.log(maior([-5, -2, -8])); // esperado -2
    DicaAdicione n e maior no Watch e dê Step over volta a volta. Quando maior deveria trocar?
    Resposta
    • A comparação está invertida: n < maior deveria ser n > maior.
    • Começar em 0 quebra listas só de negativos. Comece com lista[0] (ou -Infinity).
    2 bugs · leia a mensagem de erro

    3) O botão mudo

    O botão não funciona.

    <button id="enviar">Enviar</button>

function mostrar() { alert("Enviado!"); }
document.querySelector("enviar")
  .addEventListener("click", mostrar());
    DicaO erro é aquele do "Lendo o erro": Cannot read properties of null. Por que o querySelector devolveu null?
    Resposta
    • Falta o #: querySelector("#enviar"). Sem ele, o navegador procura uma tag <enviar>.
    • mostrar() com parênteses executa na hora e passa o retorno (undefined). Passe a função: mostrar.
